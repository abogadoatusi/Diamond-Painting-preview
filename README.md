# ダイヤモンドアート図案メーカー

写真やイラストから、**ハガキサイズ（100 × 148 mm）を基準にした実寸のオリジナル図案**を作り、
**そのまま印刷して使える PDF** を書き出すためのブラウザアプリです。

## 👉 ウェブで使う

**https://abogadoatusi.github.io/Diamond-Painting-preview/**
（このURLで公開するには、下の「公開の設定」を1回だけ行ってください）

インストール不要。PC・スマホ・タブレットのブラウザで開くだけで使えます。
画像はすべて端末の中だけで処理され、**どこにもアップロードされません**（サーバーに送信する処理は一切ありません）。

- **ホーム画面に追加**すると、アプリのように全画面で起動できます
  （iPhone / iPad: 共有 → ホーム画面に追加／Android: メニュー → アプリをインストール）
- 一度開けば**オフラインでも動きます**（機内モードや電波のない場所でもOK）
- ファイル一式をダウンロードして `index.html` を直接開くだけでも動きます

### スマホ・タブレットでの操作
- 画面上部の **① 設定 / ② プレビュー / ③ 色** のタブで切り替えます
- プレビューは**タップで1粒だけ塗り替え**。指でなぞるとスクロールします
- 連続して塗りたいときは **「指でなぞって塗る」** をONにしてください
- **「全体表示」** で図案全体が画面に収まる倍率になります

## 寸法の考え方（mm 換算）

図案のマス数は「用紙サイズ − 余白 ÷ ビーズ間隔」で自動計算されます。

```
マス数（横） = floor((用紙幅 − 余白×2) ÷ ビーズ間隔)
図案の実寸   = マス数 × ビーズ間隔
```

ハガキ（100 × 148 mm）での代表例：

| ビーズ | 余白 | マス数 | 図案の実寸 | 総粒数 |
|---|---|---|---|---|
| 角 2.5 mm | 4 mm | 36 × 56 | 90.0 × 140.0 mm | 2,016 粒 |
| 角 2.5 mm | 0 mm | 40 × 59 | 100.0 × 147.5 mm | 2,360 粒 |
| 丸 2.8 mm | 4 mm | 32 × 50 | 89.6 × 140.0 mm | 1,600 粒 |
| 角 3.0 mm | 4 mm | 30 × 46 | 90.0 × 138.0 mm | 1,380 粒 |

角ビーズは 2.5 mm、丸ビーズは 2.8 mm が流通の標準です（どちらも変更可）。
ビーズは 1 袋 200 粒前後で売られていることが多いため、必要袋数の目安も自動計算します。

## 使い方

1. `index.html` をブラウザ（Chrome / Edge / Safari）で開く
2. **1. 画像** — 画像を選ぶ（ドラッグ＆ドロップ可）。ズームと位置でトリミングを調整
3. **2. 仕上がりサイズ** — 用紙プリセット・余白・ビーズ形状・間隔を選ぶ（実寸とマス数がその場で表示されます）
4. **3. 色と画質** — 色数（既定 20、最大 60）や明るさ・彩度を調整。設定を変えると自動で作り直されます
5. **カラーパレット（右側）** — 番号や色をここで変更します
   - 行をクリック → その色が「塗る色」になり、プレビューを 1 粒ずつクリック／ドラッグで修正できます
   - 番号欄に直接入力（例: `310`）→ DMC プリセットにあれば色も自動で合わせます
   - 色見本をクリック → 色選択ダイアログ（番号検索・近い色の一覧・任意の HEX 入力・自社番号の入力）
   - `CSV読込` で、取引先のビーズ色見本（`code,hex,name`）に丸ごと差し替えられます
6. **4. PDF出力の設定** — 作品名と出力するページを選ぶ
7. **PDFを書き出す**

`スポイト`（または Alt＋クリック）で、図案上の色をパレット選択に取り込めます。
`Ctrl/Cmd + Z` で元に戻せます。作業内容はブラウザに自動保存され、次に開いたとき復元されます。

## 書き出される PDF

| ページ | サイズ | 用途 |
|---|---|---|
| 実寸チャート | 用紙サイズちょうど（例 100 × 148 mm） | **これを印刷して下地にする。**薄く色を敷いた各マスに記号が入り、10マスごとに太罫、四隅にトンボ |
| 拡大チャート | A4（1マス既定 6 mm・自動でページ分割） | 手元で見ながら貼るための拡大版。行・列番号つき |
| 色一覧 | A4 | 完成イメージ、実寸情報、記号・カラーコード・必要粒数・必要袋数（10%予備込み） |

### 印刷時の注意
- **必ず「実際のサイズ／100%／倍率調整なし」で印刷**してください（「用紙に合わせる」にすると寸法が狂います）
- 実寸チャートはフチなし印刷、または余白を 4 mm 以上に設定した状態で印刷してください
- ハガキ用紙・厚手のマット紙が扱いやすいです
- 貼り付けには、印刷面に **透明の粘着シート（A4のり付きシート等）** を重ねる方法か、
  **粘着シート付き用紙に直接印刷**する方法があります

## カラーコードについて

同梱の `js/dmc.js` は DMC 番号に対応する **近似 RGB** です（メーカー公表値ではありません）。
実際のビーズはロットや業者で色味が変わるため、次の方法で自由に置き換えてください。

- パレットの番号欄に直接入力（`自社1番` のような独自番号でも可）
- 色見本クリック → HEX を直接指定
- `CSV読込` で一括差し替え

CSV の形式（1行目のヘッダーは任意）:

```csv
code,hex,name
310,#000000,Black
3852,#D9A22C,Straw VDK
myA-01,#FF88AA,自社ピンク
```

`hex` を空にして `code` だけ書いた場合、DMC プリセットに一致すればその色が使われます。

## ファイル構成

```
index.html      画面
styles.css      スタイル
build.js        1枚のHTMLにまとめるスクリプト（-> dist/index.html）
manifest.webmanifest  ホーム画面に追加するための情報（PWA）
sw.js           オフライン用サービスワーカー
icons/          アプリアイコン
.github/workflows/pages.yml  GitHub Pages への自動デプロイ
js/dmc.js       DMC 相当のカラーパレット（近似値・差し替え可）
js/color.js     sRGB ↔ CIE Lab 変換と色差計算
js/quantize.js  格子サンプリング / k-means++ 減色 / 誤差拡散 / 孤立粒の除去
js/render.js    キャンバス描画（プレビュー・PNG書き出し共通）
js/pdf.js       依存ライブラリなしの最小 PDF ライター（mm 座標・標準フォント・JPEG埋め込み）
js/app.js       アプリ本体
```

外部ライブラリ・外部への通信は一切ありません。読み込むのは自分自身のファイルだけです。

## 公開の設定（最初の1回だけ）

GitHub の仕様上、**Pages の有効化だけは手動**です
（ワークフローの権限では作成できません）。

1. リポジトリの **Settings** → 左メニュー **Pages** を開く
2. **Build and deployment** の **Source** を **GitHub Actions** に変更
3. **Actions** タブ → 「Deploy to GitHub Pages」→ **Run workflow** で実行

以降はデフォルトブランチへ push するたびに自動でデプロイされます。

## 公開の仕組み

`.github/workflows/pages.yml` により、デフォルトブランチへ push すると
GitHub Actions が GitHub Pages へ自動デプロイします（ビルド工程はなく、リポジトリの中身をそのまま配信）。
ワークフローの `on.push.branches` にはデフォルトブランチ名を書いています。
ブランチ名を変えたときはここも合わせて変更してください。

## 1枚のHTMLにまとめる

`node build.js` を実行すると、CSS と JS を埋め込んだ `dist/index.html`（約98KB）が生成されます。
メール添付やチャットで丸ごと渡したいとき、claude.ai の Artifact として公開したいときに使います。
`js/` や `styles.css` を編集したら作り直してください。

Artifact として開かれている場合、PDF などの保存は claude.ai の
`downloads` 機能を経由します（保存前に確認ダイアログが出ます）。
通常のブラウザではそのままダウンロードされます。

更新はサービスワーカーが裏で取得し、**次に開いたときに反映**されます
（すぐに反映したい場合はページを2回読み込んでください）。

### 技術メモ
- 減色は CIE Lab 空間での k-means++ → 各クラスタ中心を DMC 色へ重複なしにスナップ
- PDF は自前生成。文字は標準14書体（Helvetica）を使うため PDF 内の英数字ラベルは英語表記、
  日本語の作品名は canvas で画像化して埋め込んでいます
- 保存プロジェクト（JSON）には元画像・設定・パレット・1粒ごとの配色がすべて含まれます
